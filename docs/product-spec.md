# UNIVERSAL RELIGION & SACRED TEXT ATLAS
## Codex Build Specification
### Working title: "Humanity's Search for Meaning"

---

# 1. PRODUCT MISSION

Build an interactive research application that allows users to explore, compare, and analyze religious, spiritual, mythological, philosophical, esoteric, apocryphal, adversarial, skeptical, and ancient texts across cultures and time.

The app must not attempt to prove that one religion, philosophy, scripture, or worldview is "correct" and another is "wrong."

The goal is to provide a broad, transparent, non-sectarian picture of humanity's attempts to explain:

- creation
- consciousness
- the soul
- God or gods
- good and evil
- death
- the afterlife
- reincarnation
- judgment
- suffering
- morality
- free will
- destiny
- prayer
- ritual
- sacrifice
- prophecy
- enlightenment
- salvation
- knowledge
- power
- sexuality
- family
- war
- peace
- wealth
- poverty
- justice
- forgiveness
- love
- fear
- demons
- angels
- spirits
- sacred law
- social order
- rebellion
- hidden knowledge
- the end of the world
- the purpose of human life

The application should function like an interactive atlas of human belief, not like a devotional product, apologetics tool, atheist critique site, or religious ranking system.

Core principle:

> The app does not decide what is true. It shows what humanity has said about truth, how those ideas developed, where they overlap, where they conflict, and what evidence exists for historical relationships between them.

# 2. PRODUCT PILLARS

The product must be designed around six pillars:

1. **Text-first**
   - Always anchor analysis to actual primary texts where possible.
   - Separate direct quotations from summaries and model-generated interpretation.

2. **Historically aware**
   - Every text should have date range, geography, language, cultural context, authorship notes, canon status, and source reliability.

3. **Globally inclusive**
   - Do not focus only on Abrahamic religions.
   - Include traditions from Africa, Asia, the Americas, Oceania, Europe, the ancient Near East, Indigenous cultures, and smaller or less familiar traditions.

4. **Neutral by design**
   - The system must avoid presenting one religion as superior.
   - It must not implicitly treat mainstream religions as "truth" and alternative texts as "false."
   - It must not implicitly treat skepticism as more rational than religion.

5. **Transparent about uncertainty**
   - Clearly distinguish:
     - primary text
     - religious tradition
     - historical fact
     - scholarly consensus
     - scholarly debate
     - interpretation
     - model inference
     - speculation

6. **Interactive**
   - Users should be able to explore beliefs by:
     - question
     - tradition
     - text
     - theme
     - time
     - geography
     - influence
     - similarity
     - contradiction
     - canon status
     - worldview category

# 6. "SHOW THE OPPOSITION" MODE

This is a major differentiator.

The user selects a doctrine, concept, or text and clicks:

**Show the Opposition**

The system then intentionally surfaces viewpoints that:

- reject the concept
- invert the concept
- reinterpret the concept
- challenge authority
- deny supernatural claims
- emphasize human autonomy
- offer competing cosmology
- present hidden knowledge
- criticize religious institutions

Example:
User selects **obedience**.

The app may show:

- canonical monotheistic teachings on obedience
- Stoic duty
- Buddhist discipline
- Gnostic distrust of the material ruler
- adversarial modern Satanic emphasis on self-sovereignty
- Nietzschean critique
- secular humanist critique
- anarchist religious critique
- mystical reinterpretations

Important:
Never flatten all non-orthodox traditions into "Satanic" or "evil."

# 11. SOURCE RELIABILITY MODEL

Every generated claim must carry a confidence badge.

Levels:

### Level A - Primary source
Directly supported by the source text.

### Level B - Strong scholarly consensus
Widely accepted historical or textual conclusion.

### Level C - Scholarly majority
Common interpretation but not universal.

### Level D - Disputed
Meaningful scholarly disagreement.

### Level E - Speculative
Interesting hypothesis lacking strong evidence.

Use visual badges.

Never present Level D or E claims without explicitly labeling them.

# 14. NEUTRALITY AUDIT

Before displaying an AI synthesis, run a secondary evaluation.

Check:

- Did the answer portray one religion as obviously true?
- Did it portray another as primitive?
- Did it use Christian/Western categories as universal defaults?
- Did it incorrectly call an oral tradition "scripture"?
- Did it confuse mythology with falsehood?
- Did it confuse canonical with historically true?
- Did it present skepticism as automatically superior?
- Did it present religious belief as automatically irrational?
- Did it overstate textual borrowing?
- Did it ignore chronology?
- Did it confuse similarity with direct influence?
- Did it omit alternative scholarly interpretations?

If flagged, regenerate.

# 19. TEXT COPYRIGHT RULES

This is critical.

Many ancient works are public domain as ideas/texts, but modern translations may still be copyrighted.

Rules:

1. Store complete text only when public-domain or licensed.
2. For copyrighted translations:
   - store metadata
   - store short excerpts only where legally permitted
   - link to source
   - allow user-provided licensed content
3. Track translator and edition.
4. Never treat a translation as the original-language text.
5. Support multiple translations.

Add `copyright_status` and `license` fields to every passage and image.
