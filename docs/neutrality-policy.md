# Neutrality policy

No religion truth scores or rankings. Canonical does not mean historically verified; non-canonical does not mean false. Skeptical, adversarial, esoteric and oral traditions are distinct and are not collapsed into one category. Original-language concepts must not be assumed equivalent because an English translation uses the same word.

The local engine only selects and labels evidence. Optional model output must reference the supplied segment IDs, avoid ranking or borrowing assertions unsupported by evidence, and pass a second audit request. This automated check is fallible and is not a substitute for scholarly review.

Chronology, similarity, literary function and historical transmission are different questions. Sparse data is presented as missing. Quoted historical prejudice belongs to the source, not the application’s editorial voice.
